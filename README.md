# Dashboard Python — Analyse de transactions

Application web interactive développée avec Python et Dash pour explorer des données de transactions clients.

Le dashboard permet notamment de visualiser :
- l'évolution du chiffre d'affaires ;
- les catégories de produits les plus performantes ;
- les transactions récentes ;
- différents indicateurs selon la zone géographique sélectionnée.

## Technologies

Python · pandas · Dash · Plotly

## Lancer l'application

```bash
pip install -r requirements.txt
python app.py
```
